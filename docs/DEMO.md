# Демонстрация за 3–4 минуты

Запуск из корня репозитория: `python -B -m windagent serve`. Открыть http://127.0.0.1:8080. Для подготовки без интернета можно заранее выполнить `python -B -m windagent demo --backtest`.

1. **Задача, 20 секунд.** «Мы прогнозируем почасовую нормализованную мощность двух ветротурбин на следующие 24–48 часов. Это помогает заранее оценивать ожидаемую генерацию».
2. **Честно назвать данные.** «Сейчас показываем учебную синтетику, потому что реальная история ещё не подключена. Эти числа не являются точностью на объекте».
3. **Запустить прогноз.** Выбрать 31 января 2026, 23:00, горизонт 48 часов. Показать почасовой график, переключить турбину и открыть таблицу. «Модель учится связи скорости ветра, температуры и мощности по истории до выпуска».
4. **Показать самостоятельные решения.** Открыть журнал: проверка истории, получение погоды, проверка доступности, модель, анализ, сохранение. Нажать проверку обновлений: при тех же данных система повторно использует расчёт, при изменении входов создаёт новую версию.
5. **Показать февраль.** Запустить ретропрогноз. Объяснить 29 выпусков, 672 часа на турбину и отдельное хранение перекрывающихся горизонтов. Экспортировать CSV.
6. **Проговорить основной риск.** «Мы не заменяем архивный прогноз погодными фактами. Дата запуска модели и дата публикации различаются. Для выбранного архива требуется подтверждение оперативного происхождения и времени доступности; пока мы явно помечаем это ограничение».

Если спросят «где AI»: обучаемая модель строит кривую мощности; управляющий агент по правилам выбирает модель, проверяет источники, обнаруживает изменения и выполняет повторный расчёт. Это не LLM-чат и не ручная последовательность скриптов. Не утверждать, что используются нейросети или языковая модель.

Если спросят «какая точность»: на реальной ВЭС ещё не измерена. Ошибка на истории с измеренной погодой описывает только преобразование погоды в мощность; нужна отдельная оценка всей цепочки с архивными прогнозами. Простое сравнение — последняя известная мощность сохраняется.

Перед реальным выступлением: получить историю, проверить импорт, подтвердить архив, уточнить шкалу мощности и временную конвенцию, сделать отдельное рабочее пространство реального расчёта, заранее сохранить ответы API и CSV. Не выдавать учебный CSV за submission.
