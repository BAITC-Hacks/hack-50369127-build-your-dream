# Демонстрация за 3–4 минуты

Основной показ использует подключённый **реальный проект**, а не синтетическое демо. Работайте из корня репозитория и используйте одну папку результатов последовательно, без одновременно запущенных CLI и сервера.

## Подготовка

Для уже импортированного проекта достаточно проверить среду и открыть сохранённое состояние:

```powershell
python -B -m windagent doctor
python -B -m windagent serve
```

Откройте **http://127.0.0.1:8080**. Если сервер уже запущен, используйте его вместо второго процесса. `doctor` не запускает прогноз; повторный импорт и ретротест перед каждым показом не нужны. Если рабочее пространство пустое, используйте раздел первого импорта в [README](../README.md#импортировать-проект-впервые).

Веб-панель должна показывать «Реальные данные · архив проекта», «Кеш проекта · ECMWF» и UTC. Для показа первого февральского выпуска нужен сохранённый прогноз на **31 января 2026, 23:00 UTC**. Простое изменение даты в форме не заменяет уже показанный результат.

Перед выступлением проверьте `execution` у результата. `recomputed` означает новый запуск native CatBoost; `saved_archive` — чтение готовых значений из архива без нового запуска модели. Второй вариант пригоден для демонстрации интерфейса и происхождения данных, но его нужно так и назвать. Среда для нового расчёта описана в [README](../README.md#новый-расчёт-или-сохранённый-результат).

| Что показываем | Нужно ли заново выполнять расчёт |
|---|---|
| Готовая панель, график, журнал и CSV | Нет: открыть уже сохранённое состояние |
| Новый прогноз существующей CatBoost | Да: отдельный `forecast --mode project --refresh` или действие в панели |
| Независимое повторное обучение | Это отдельная задача; открытие панели и новый прогноз её не выполняют |

Первый новый native-расчёт уже выполнен: **96 значений, максимальное отличие от архива — 0**. Не распространяйте этот вывод на все 29 выпусков или на повторное обучение без соответствующей записи в [VERIFICATION.md](VERIFICATION.md). Для нового расчёта из CLI предварительно остановите сервер; после завершения снова выполните `serve`.

Короткая речь и объяснение терминов — [TEAM_GUIDE.md](TEAM_GUIDE.md). `.env.example` служит справкой и автоматически не применяется; переменные задаются в терминале до запуска приложения.

## Что показать

1. **Задача, 20 секунд.** «Система формирует почасовой прогноз нормализованной мощности двух турбин на 24–48 часов и сохраняет, какие данные использовала».
2. **Исходные данные.** Откройте «Исторические данные»: реальные CSV дают 48 452 полных турбино-часа. История заканчивается 31 января в 23:50; февральских фактов нет. Выборка финальной CatBoost содержит 36 632 строки и показана отдельно от объёма телеметрии.
3. **Прогноз.** Покажите выпуск 31 января, график, переключение турбин и таблицу. Если статус `recomputed`: «Модель выполнена заново на признаках погодного кеша». Если `saved_archive`: «Это сохранённый расчёт из переданного архива; сейчас модель не запускалась».
4. **Решения агента.** Покажите журнал, время погодного выпуска, основание доступности и хеш. Объясните кнопку «Проверить кеш проекта»: она проверяет локальные входы; новая погода из сети здесь не загружается. Нажимайте её только если хотите отдельно показать проверку/новый расчёт, а не просто открыть готовый результат.
5. **Февраль и выгрузка.** Откройте ретроспективный тест: выпуски идут последовательно; перекрывающиеся горизонты хранятся отдельно. Для полной сетки февраля требуется 672 часа каждой турбины. Submission содержит первые 24 часа каждого выпуска — 1344 строки.
6. **Оценка и ограничения.** На странице данных покажите январские метрики. «MAE около 18,60 процентного пункта, RMSE около 25,72. Мы перепроверили арифметику по 2928 сохранённым прогнозам; январская модель независимо ещё не переобучена. Это не ошибка за февраль».

## Ответы на вопросы

**Где AI и автономность?** CatBoost преобразует прогнозные метеопризнаки в мощность. Управляющий агент проверяет допустимость времени и полноту данных, использует инструмент погоды, получает прогноз, анализирует его и сохраняет версии входов. Это управляющий цикл по правилам; LLM в текущем интерфейсе не требуется.

**Почему нельзя объявить полное соответствие кейсу?** Время инициализации погоды отличается от времени публикации. Архив предполагает доступность через 8 часов, но исторический журнал публикаций и оперативное происхождение ранней ECMWF-серии/hindcast не подтверждены. Также ещё нужно подтвердить UTC и смысл временной метки телеметрии.

**Почему нет точности за февраль?** Предоставленные CSV заканчиваются 31 января, несмотря на февраль в именах отдельных файлов. Для проверки февраля нужны отдельные фактические значения. Внешние факты для оценки не должны попадать в обучение.

**Это МВт·ч?** Нет. Показывается нормализованная мощность. Для физических единиц нужны номинальные мощности турбин; среднее двух турбин не равно энергии станции.

## Запасной синтетический показ

Если нужен самостоятельный учебный пример, сохраните реальный проект и откройте другую папку:

```powershell
python -B -m windagent --workspace "$env:TEMP/wind-agent-demo" demo --backtest
python -B -m windagent --workspace "$env:TEMP/wind-agent-demo" serve --port 8081
```

На **http://127.0.0.1:8081** честно назовите данные синтетическими. Учебный режим имеет отдельный сценарий UTC+5 и работает без интернета. Не переносите его метрики или CSV в результаты реальной станции.

## Ручная проверка панели перед показом

Автоматизированная визуальная проверка в текущем сеансе **не выполнена**: инструмент управления вернул пустой список браузеров и «No browser is available». Проверены только HTTP-ответы, согласованность HTML/JavaScript, функции построения графика/таблицы на фактическом состоянии API и содержимое CSV. Это не проверка внешнего вида, наведения мыши или скачивания через браузер.

Для проверки ниже должен быть уже сохранён выпуск **31.01.2026 23:00 UTC, 48 часов**, содержащий 96 строк. Проверка UI-контракта ранее выполнялась со статусом `saved_archive`; затем отдельно подтверждён один native-расчёт. Поэтому смотрите фактический статус открытого результата. Эти действия не требуют импорта, нового расчёта или запуска ретротеста.

| Действие в браузере | Ожидаемый результат |
|---|---|
| Открыть `http://127.0.0.1:8080` | Панель без пустого экрана; «Реальные данные · архив проекта», «Кеш проекта · ECMWF», UTC; предупреждение о происхождении погоды |
| Посмотреть график и навести указатель на линию | Целевые часы 1 февраля 00:00 — 2 февраля 23:00 UTC; подсказка показывает время, мощность в процентах и ветер |
| Выбрать «Турбина 1», затем «Турбина 2» | Для каждой доступны 48 часов; график, средняя мощность и таблица относятся к выбранной турбине |
| Вернуть «Среднее двух турбин» | Значения — среднее нормализованной мощности; единицы не меняются на МВт/МВт·ч |
| Нажать «Показать все часы», затем свернуть таблицу | Счётчик меняется с 8 из 48 на 48 из 48 и обратно |
| Выбрать 24 часа, не запрашивая прогноз | Выбран новый горизонт, но сохранённый график остаётся 48-часовым; карточка поясняет, что выбор применится после запроса. Вернуть 48 часов |
| Открыть «Исторические данные» | 48 452 строки телеметрии, модель импортирована; отдельно 36 632 строки обучения CatBoost. В январской таблице читаемые подписи турбин и горизонтов, не `ALL`; общие MAE/RMSE CatBoost около 18,6/25,7 п. п. |
| Вернуться к журналу и происхождению данных | При `saved_archive` явно сказано «Сохранённый расчёт из архива» и что модель не запускалась. Есть время погодного выпуска, хеш и оговорка о доступности |
| Выбрать одну турбину и нажать «Скачать CSV» в почасовой таблице | Скачивается файл с 96 строками данных **обеих турбин**; это указано над таблицей. В CSV есть время выпуска, целевой час, мощность, происхождение и `execution` |
| Открыть «Ретроспективный тест», не нажимая запуск | Уже сохранённый отчёт: 29 выпусков, покрытие 672 часа на турбину, 2640 строк перекрывающихся прогнозов; CSV отчёта содержит 2640 строк данных |
| Открыть локальную ссылку `http://127.0.0.1:8080/api/export?kind=submission` | Скачивается submission: 1344 строки данных, по одной на каждую турбину и февральский час |
| Сузить окно браузера и пройти элементы клавишей Tab | Меню, выбор турбины и кнопки остаются доступны; фокус виден; широкие таблицы прокручиваются внутри карточки |

Число строк выше не включает строку заголовков CSV. Если в сервере выбран другой выпуск или ещё нет ретротеста, сначала подготовьте его отдельно по инструкции выше. До окончания параллельной работы не нажимайте «Рассчитать прогноз», «Проверить кеш проекта», «Запустить тест» и кнопки импорта: они меняют состояние сервера.
