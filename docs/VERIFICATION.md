# Проверка MVP · 23 сентября 2026

Окружение: Windows, Python 3.14.4, Node.js 24.15.0. Внешние Python-пакеты не устанавливались.

## Выполнено

- `python -B -m unittest discover -s tests -v` — **31 тест, все прошли**: 11 проверок данных/модели, 11 проверок агента и 9 проверок погодного адаптера с подменёнными ответами API.
- `node --check web/app.js` — синтаксических ошибок нет.
- Статическая проверка HTML/JS — 72 уникальных HTML id; 52 прямые ссылки JavaScript на элементы разрешаются в статические или создаваемые самим скриптом элементы.
- `git diff --check` — ошибок пробелов нет; Git сообщает только о преобразовании LF/CRLF в Windows.
- Локальный сервер действительно запущен, HTTP-запросы выполнялись к `http://127.0.0.1:8080`.

## Проверенный HTTP-сценарий

1. Исходное состояние без истории; HTML, CSS и JS успешно отдаются сервером.
2. `POST /api/demo` создаёт синтетическую историю и обучает модель.
3. `POST /api/forecast`: выпуск 31 января, 23:00 UTC+5, 48 часов, режим demo → **96 строк**.
4. Повтор с `refresh=true` → тот же идентификатор и `reused=true`.
5. `POST /api/backtest` → **29 выпусков**, 2640 строк всех перекрывающихся прогнозов февраля, **672 часа каждой турбины**.
6. `GET /api/export?kind=submission` → **1344 уникальные пары турбина/час**, CSV корректно разбирается.
7. Некорректный CSV → HTTP 400 и понятная ошибка; ранее загруженное состояние сохранено.
8. Учебная история с режимом archive → HTTP 400: источники не смешиваются.
9. Восстановлен учебный 48-часовой выпуск 31 января для первого открытия панели.

## Не проверено и не заявляется

- Внешний погодный API: сетевой запрос заблокирован средой, повтор с расширенными правами ожидал подтверждения и был прерван. Автономные тесты не подтверждают работу живого endpoint.
- Внешний вид и клики браузером: инструмент сообщил, что подключённых браузеров нет. Проверены выдача файлов, синтаксис, ссылки на элементы и API, но это не заменяет визуальную проверку.
- Точность на реальных данных ВЭС: история не предоставлена.
- Соответствие архива строгому условию исторической доступности: источник требует дополнительного подтверждения, см. [WEATHER.md](WEATHER.md).

Перед демонстрацией откройте панель браузером, переключите турбину и горизонт, проверьте график и скачивание CSV. Перед реальной сдачей выполните также пункты из раздела «Перед сдачей» в README.
