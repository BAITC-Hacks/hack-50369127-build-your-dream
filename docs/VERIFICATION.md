## Автоматические проверки

Команда основного приложения без внешних зависимостей: `python -B scripts/test_app.py`. Дополнительно: `node --check web/app.js`, `git diff --check`.

Итоговый запуск scripts/test_app.py: **56 тестов, все прошли** за 10,26 секунды. Из них 17 проверяют импорт проекта, погодный кеш и контракт отдельного worker.

Покрыты временные отсечки, отсутствие будущих меток, агрегация телеметрии, целостность архивов, подмена времени выпуска, единицы погоды, признаки, связь прогноза с турбиной/часом, инвалидирование кеша, сохранённый replay и контракт worker. Тесты worker используют подменённый CatBoost; они не доказывают реальную загрузку CBM.

Синтаксис JavaScript и ссылки HTML/JS проверены. Визуальная проверка браузером не выполнена: инструмент не обнаружил подключённых браузеров.

## Что ещё не подтверждено

- **Новый native CatBoost inference и повторное обучение.** Установка библиотеки в sandbox не нашла дистрибутив; запрос с расширенными правами ожидал разрешения и был прерван до запуска. Это не установленный отказ пользователя. Локальный CatBoost/wheel не найден. Подготовка среды описана в README.
- **Живое получение погоды.** Проектный сценарий использует предоставленный кеш. Ранее внешний запрос базового адаптера был ограничен средой; тесты с подменённым API не доказывают сетевую доступность.
- **Историческая доступность погоды и UTC телеметрии.** Задержка 8 часов и UTC сохранены как явные предположения исходного проекта. Ограничение раннего ECMWF-архива/hindcast не снято; см. [WEATHER.md](WEATHER.md).
- **Февральская точность.** Фактическая мощность февраля отсутствует; MAE/RMSE за февраль не вычислены.
- **Исследовательский бэкенд src/.** Его код и отчёты добавлены параллельным слиянием. Корневой VERIFICATION.md содержит заявления исходного проекта. Дополнительные test_pipeline.py и test_models_agent.py требуют исследовательских зависимостей и в текущей среде независимо не запускались.

Архивные Python-скрипты и joblib-файлы для подключения веб-панели не исполнялись. Нативный CBM передаётся только отдельному worker после установки CatBoost.
