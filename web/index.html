    Формат данных

    CSV должен содержать время, идентификатор турбины, скорость ветра, нормализованную активную мощность и температуру. Время без часового пояса интерпретируется согласно выбранному поясу при импорте.

    timestamp,turbine_id,wind_speed,power,temperature
2025-01-01T00:00:00+05:00,1,7.2,0.31,-4.5
2025-01-01T00:00:00+05:00,2,7.5,0.34,-4.3

    Пример содержит условные значения. По умолчанию мощность задаётся долей от 0 до 1; для процентов выберите масштаб 100 при импорте. Если исходные файлы записаны в UTC+6, выберите этот пояс явно.

    Как работает Wind Agent

    01

    Получает погоду

    Обращается к архиву прогнозов по координатам двух турбин. Фиксирует время выпуска и допущения о доступности.

    02

    Готовит данные

    Проверяет временные метки, пропуски и физические границы. Объединяет погодные признаки с историей станции.

    03

    Рассчитывает мощность

    Использует обученную модель, чтобы получить почасовую нормализованную мощность каждой турбины.

    04

    Проверяет и обновляет

    Анализирует покрытие и предупреждения. По запросу проверяет новые входные данные и повторяет расчёт при изменениях.

    Что важно для честного прогноза

    Для ретроспективного теста нельзя подменять погодный прогноз фактическими измерениями или реанализом. Выпуск и публикация прогноза должны предшествовать моменту расчёта.

    Архив Open-Meteo Single Runs за февраль 2026 года требует дополнительной проверки: исторические запуски могут быть помечены как hindcast, а время фактической публикации каждого запуска не подтверждено. Расчёты с этим источником не являются готовым доказательством отсутствия утечки.

    Синтетический режим нужен для демонстрации интерфейса и полного цикла агента. Он не измеряет качество на реальной ВЭС. Точность за февраль можно оценить только при наличии фактической выработки за этот период.

    «Среднее двух турбин» — арифметическое среднее нормализованной мощности. Для расчёта суммарной мощности и энергии нужны номинальные мощности турбин.
